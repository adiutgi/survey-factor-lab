Redundancy threshold
Two questions that correlate at or above this value are treated as duplicates, and one is dropped. Lower it and more questions are dropped. Raise it and fewer are.
Components
How many dimensions the tool extracts. Auto keeps each dimension that explains more than a single question does. Pick more and the dimensions get narrower. Pick fewer and they get broader.
Loading cutoff
How strong a question's highest loading must be for it to be highlighted. Each question is highlighted under one dimension at most. This changes the highlighting only, not the numbers.
Rotation
Varimax turns the dimensions so each question lines up with mainly one, which makes them easier to name. It is always applied.

The logic behind the tool

Factor analysis asks one question: if customers' answers to twenty questions rise and fall together in a few patterns, what are those patterns? Each pattern is a service dimension customers actually perceive, such as "speed" or "staff friendliness". The tool finds them in four moves.

1. Correlate

Each column is put on a common scale, so columns measured in different units or ranges count equally. The correlation matrix then shows, for every pair of questions, how strongly the two move together: when one is high, is the other high too?

2. Remove near-duplicates

When two questions correlate above the threshold (0.85 by default), customers are treating them as the same question. Keeping both double-weights that dimension and adds survey length with no new information, so one is dropped. By default the tool keeps the one listed first; you can override each decision.

3. Extract components (PCA)

Principal Component Analysis finds the eigenvectors of the correlation matrix. Each eigenvalue says how many questions' worth of variance that component explains. A component with eigenvalue above 1 explains more than a single question does, so it is kept (Kaiser rule). The scree plot shows where the curve flattens.

4. Rotate (Varimax) and read the loadings

Raw components are hard to read because most questions load a little on everything. Varimax rotates the axes so each question loads strongly on one component and weakly on the rest, without changing how much total variance is explained. A loading is the correlation between a question and a component. Each question is assigned to the component where its loading is highest, provided that loading is 0.5 or more. Questions assigned to the same component form a dimension; you name it by reading them.

5. Link to outcomes

Each respondent gets a score on every dimension (regression method: Z · R⁻¹ · L). Regressing overall satisfaction on those scores shows which dimensions move satisfaction most.

Diagnostics

  • KMO (0 to 1) measures whether correlations are driven by shared factors. Above 0.8 is good, above 0.6 is acceptable, below 0.5 means factor analysis is not appropriate.
  • Bartlett's test checks the questions are correlated at all. A p-value below 0.05 means they are.

The math runs in your browser; uploaded files are not sent anywhere. Results match SPSS "Principal Component Analysis, Varimax with Kaiser Normalization" up to sign and column order.
